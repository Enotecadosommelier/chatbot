# Etapa 8 — Cardápio Visual

`cardapio-visual.html` é o cardápio pronto para virar PDF ou imagem de WhatsApp:

1. Abra o arquivo no navegador.
2. Substitua o número de WhatsApp de exemplo pelo número real.
3. Use "Imprimir → Salvar como PDF" (tamanho A4) para gerar o PDF de envio.
4. Para enviar como imagem no status/WhatsApp, tire um screenshot da página already renderizada (ou converta o PDF gerado em JPG/PNG em qualquer conversor local).

O conteúdo (produtos, descrição curta, preço) segue exatamente o cardápio da
Etapa 3 — sempre que um preço mudar na ficha técnica, atualizar aqui também.
