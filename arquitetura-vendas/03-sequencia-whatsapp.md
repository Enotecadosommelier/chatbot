# SEQUÊNCIA WHATSAPP — VINO BIANCO STORE
## Funil de Vendas via WhatsApp Business API

---

## ESTRATÉGIA GERAL

O WhatsApp é o canal de maior conversão do Brasil (taxa de abertura ~98% vs 25% do email).
Usar para:
1. Nutrição de leads quentes (que já baixaram o lead magnet)
2. Recuperação de carrinho abandonado (integração Hotmart + Make)
3. Relacionamento pós-compra (retenção e upsell)
4. Lançamentos e campanhas sazonais

**Ferramenta recomendada:** Z-API ou Wati.io (integração com Make.com)
**Conta:** WhatsApp Business API (não o app — permite automação)

## CONFIGURAÇÃO TÉCNICA (Z-API + Make)

### Variáveis de Ambiente
```
ZAPI_INSTANCE_ID=SUA_INSTANCIA
ZAPI_TOKEN=SEU_TOKEN
WHATSAPP_NUMBER=5511XXXXXXXXX  # Número da Vino Bianco Business
```

### Endpoint para Envio
```
POST https://api.z-api.io/instances/{INSTANCE_ID}/token/{TOKEN}/send-text

Body:
{
  "phone": "55{{telefone_limpo}}",
  "message": "{{mensagem_personalizada}}"
}
```

### Regras de Opt-in (LGPD)
- Coletar confirmação explícita no formulário: "Aceito receber mensagens no WhatsApp"
- Incluir opção de cancelamento em TODA mensagem: "Para parar de receber, responda SAIR"
- Processar SAIR automaticamente via Make → tag "descadastrado" no CRM
- Nunca enviar mais de 1 mensagem por dia
