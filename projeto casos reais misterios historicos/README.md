# 🕵️ Casos Reais Incríveis e Mistérios Históricos Documentados

Canal Dark (faceless) no nicho de **casos reais e mistérios históricos documentados**, subnicho inicial: *Sobrevivências Improváveis e Mistérios Não Resolvidos*.

## Por que este nicho

- **Retenção alta por design**: histórias reais com final incerto seguram o espectador até o fim (watch time = principal fator de ranqueamento do YouTube).
- **RPM (BR)**: R$ 3,00–5,00 por mil views no mercado nacional; RPM 3–8x maior se o mesmo roteiro for adaptado para inglês/espanhol (arbitragem de conteúdo).
- **Baixo risco de direitos autorais**: eventos históricos de domínio público, sem uso de trilha/imagem protegida, apenas b-roll livre + IA generativa + narração autoral.
- **Escalável**: mesma fórmula de 18 blocos/12 min pode ser replicada semanalmente para qualquer novo caso.
